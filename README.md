# NoirCraftStudio website

A lightweight, responsive static website ready for Vercel deployment.

## Included
- `index.html` — complete one-page website
- `assets/` — add your original portfolio images here

## Add your portfolio images
Export your original designs as JPG or WebP and place them in `assets/` using these exact names:
- `aurelle-cover.jpg`
- `vantage-cover.jpg`
- `flyer-01.jpg`
- `flyer-02.jpg`

You can add more portfolio cards later. Do not use blurry screenshots if you have the original exported artwork.

## Deploy on Vercel using GitHub
1. Extract this ZIP.
2. Create a GitHub account or sign in.
3. Create a new repository named `noircraftstudio`.
4. Upload `index.html`, the `assets` folder, and this README to the repository root.
5. Sign in at https://vercel.com/ using GitHub.
6. Choose **Add New → Project**, import `noircraftstudio`.
7. Framework Preset: **Other**. Build Command: leave empty. Output Directory: `.` (or leave default if Vercel detects the static site).
8. Click **Deploy**.

## After deployment
1. Replace `YOUR-VERCEL-DOMAIN` in `index.html` with the actual Vercel domain, in the canonical URL, Open Graph image URL and JSON-LD URL.
2. Commit the change to GitHub; Vercel will redeploy automatically.
3. Add the live website to Google Search Console and request indexing.

## Important
The portfolio image slots intentionally show text placeholders until you add your own images. The site uses only the supplied brand details and public portfolio links; no testimonials or client claims have been invented.
